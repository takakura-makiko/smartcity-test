# スマートシティデータモデル 公開テスト（smartcity-test）

GitHub Pages と w3id.org による公開手順を試すためのサンプルです。内容は架空のもので、正式なデータモデルではありません。

## 参照URI

- 版付き: https://takakura-makiko.github.io/smartcity-test/v4.0/
- テスト公開のため github.io のURLを使用（本番では w3id.org のURIに置き換える）

## 構成

- v4.0/context/ : JSON-LD Context
- v4.0/schema/ : JSON Schema
- v4.0/datatype/ : データ型（住所・位置座標）
- v4.0/codelist/ : コードリスト（施設種別）
- v4.0/example/ : サンプルデータ
